

# 🌩️ AWS vs GCP – Service Mapping (EC2 se Start)

---

## 🔵 1️⃣ AWS EC2 = GCP me kya?

| AWS                         | GCP                          |
| --------------------------- | ---------------------------- |
| EC2 (Elastic Compute Cloud) | Compute Engine (VM Instance) |

👉 AWS me EC2 hota hai
👉 GCP me **Compute Engine VM Instance**

Dono ka kaam same:

✔ Virtual Machine banana
✔ Linux/Windows server chalana
✔ SSH access
✔ Docker/Jenkins run karna

---

# 🖥️ EC2 / Compute Engine Ka Concept Same Hai

Tu basically ek cloud server create karta hai:

* CPU
* RAM
* Disk
* OS

Bas naam alag hai.

---

# 🔵 AWS vs GCP Detailed Mapping

| AWS Service | GCP Equivalent   |
| ----------- | ---------------- |

# 🔵 Ab Main Batata Hu GCP Me EC2 Jaisa VM Kaise Banate Hain

Step-by-step.

---

# 🚀 GCP Me VM Kaise Banaye (EC2 Equivalent)

---

## 🔹 Step 1: Console Open

Go to:

👉 [https://console.cloud.google.com](https://console.cloud.google.com)

Login karo.

---

## 🔹 Step 2: Project Select / Create

Top bar me:

"Select Project" → "New Project"

Project name de do.

---

## 🔹 Step 3: Compute Engine Enable Karo

Left menu → Compute Engine → VM Instances

Agar first time hai to API enable karni hogi.

---

## 🔹 Step 4: Create VM

Click: **Create Instance**

---

## 🔹 Step 5: Basic Configuration

Yaha tu AWS EC2 jaisa hi dekhega:

### 1️⃣ Name

vm-devops

### 2️⃣ Region

Free tier ke liye:
👉 us-central1

### 3️⃣ Machine Type

Free tier:
👉 e2-micro

(EC2 me t2.micro jaisa)

---

## 🔹 Step 6: Boot Disk

Ubuntu 22.04 choose kar sakta hai.

Disk type:
Standard Persistent Disk

---

## 🔹 Step 7: Firewall

Tick:
✔ Allow HTTP
✔ Allow HTTPS

---

## 🔹 Step 8: Create

Click create.

30–60 seconds me VM ready.

---

# 🔵 SSH Kaise Kare

VM list me:

"SSH" button hoga.

Direct browser se connect ho jaoge.

AWS me jaisa:

.pem key download karke ssh karte hain

GCP me direct browser SSH milta hai.

---

# 🔵 Important Difference AWS vs GCP

| Topic       | AWS        | GCP               |
| ----------- | ---------- | ----------------- |
| Billing     | Per hour   | Per second        |
| Default SSH | Manual key | Browser SSH       |
| Free Tier   | 12 months  | Always free micro |
| Naming      | EC2        | Compute Engine    |
